HIDS — Host Intrusion Detection System

Built a lightweight Host Intrusion Detection System for a personal Linux machine, from scratch — five independent monitoring modules plus real-time alerting, running as two independent systemd services (detection daemon + dashboard) so a crashed daemon can't take the dashboard down with it.

  • File integrity: real-time inotify watches plus periodic reconciliation; also hashes every binary that's earned network-level trust, so tampering after the fact still gets caught
  • Process monitoring: flags binaries running from suspicious paths or deleted from disk
  • Auth logs: streams journalctl for failed logins and sudo attempts
  • Network activity: new listening ports and outbound connections, tracked per-process and per-destination-subnet — closes the "trust forever" gap for a compromised-but-familiar process without CDN edge-IP rotation causing noise
  • Self-protection: pings an external dead-man's-switch every 2 minutes, since nothing running only on the host can reliably report its own death
  • Real-time, debounced email alerting; dashboard shows a live/stale banner derived independently of the daemon it's monitoring
TypeScript Bun Linux systemd Security Monitoring Cybersecurity

OSS CVE Research Agent

Built a Copilot-based agent that automates CVE vulnerability research and triage for open-source dependencies. It cross-references authoritative public sources — NVD, MITRE, GitHub Security Advisories, vendor advisories — to trace direct and transitive dependency chains, then classifies each CVE into one of three evidence-backed verdicts (Affected, Not Affected, Potentially Affected) rather than trusting scanner output blindly. Generates an audit-ready report per CVE with justification, dependency path, and cited evidence for every conclusion, explicitly supporting false-positive analysis when a vulnerable version, dependency, or code path isn't actually present.

AI Agents Copilot Vulnerability Management CVE Research Cybersecurity
